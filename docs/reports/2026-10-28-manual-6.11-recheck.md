## 3. 四页的新内容与去向

### 3.1 `policies/parameters.html`：`block-quic = adaptive` 与 `auto` 的新含义

- "Optional, `auto` / `on` / `off` / `adaptive`, default: `auto`."；"`adaptive`: block QUIC traffic first, and allow it if the client does not fall back to TCP. iOS 5.24.0+ Mac 6.11.0+"
- "Starting with Surge iOS 5.24.0 and Surge Mac 6.11.0, `auto` works as follows: the DIRECT policy does not block QUIC, policies that do not support UDP relay block QUIC, and all other policies use the adaptive mode."
- 机制写全了："In adaptive mode, when QUIC traffic to a hostname is detected, Surge blocks it immediately so that the client can fall back, and waits for a TCP connection to the same hostname. If a TCP connection arrives within 1 second, the client is able to fall back and QUIC stays blocked. Otherwise, QUIC traffic to the hostname is allowed from then on, and the client's next QUIC attempt goes through. The result is remembered per hostname (up to the 200 most recently used hostnames), so the detection only happens on the first attempt."
- 全局的 `[General] block-quic`（`profile/general.html`）没有变。

rurge 今天：`adaptive` 是错误（`E0018`，一个参数取了不认识的值），带着它的 Profile 加载不了；`auto` 照 6.10 的写法（代理阻断、DIRECT 不阻断）。**去向：M5 实现**（M5 设计第 6.2 节、M5-D5）。

### 3.2 `policies/wireguard.html`：`listen-port`、`accept-incoming`

- "Surge connects to its peers by default. With `listen-port`, it also accepts peers connecting to it, so it can serve WireGuard clients such as phones or laptops (iOS 5.24.0+ Mac 6.11.0+)."
- `accept-incoming`："Accept connections that the peer side opens through the tunnel."（经规则、出现在请求记录里；发往 `self-ip` 的交给本机）。
- `listen-port`："Listen for peers on this UDP port"；"A peer may omit `endpoint`. Surge learns the peer's address from its first valid handshake …"；"Implies `accept-incoming`."

rurge 今天：这两个键在 `[WireGuard <名字>]` 里是 `W0001`（未知的键，忽略），**没有 `endpoint` 的 peer 是 `E0023`**——手册自己的例子（`listen-port = 51820`、两个不带 `endpoint` 的 peer）在 rurge 里加载不了，违反"不认识或平台不适用的配置项解析并忽略、记录日志、不报错"（`CLAUDE.md`「工作流约定」）。**去向**：接受连入（WireGuard 作服务端）随阶段 7（服务端能力）；M5 只让这些写法能加载、说清不生效（M5 设计第 10.2 节、M5-D17）。

### 3.3 `policies/tailscale.html`：`accept-incoming`、`advertise-exit-node`、`advertise-routes`

三个键都在 `[Tailscale <名字>]` 节里。rurge 今天把这种节整个当作"解析了、这一版不生效"（`W0016`），`tailscale` 策略在清单里是远期。**去向**：只登记，不改代码。

### 3.4 `tools/http-api.html`：`GET /v1/policies?include_external=true`

"Add the query parameter `include_external=true` to also list the policies loaded by external policy groups (`policy-path`). iOS 5.24.0+ Mac 6.11.0+"；结果多一个 `external-policies` 字段（每项 `name`、`group`、`identifier`）。**去向**：只登记，阶段 6（API 与 Dashboard）。
